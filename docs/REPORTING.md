# Reporting a problem

Use the website's **Report Center** to prepare a complete report for:

- Crashes or broken features
- Recording, video, audio, or microphone problems
- FFmpeg installation and detection
- UI, controls, and accessibility
- Performance and encoding
- Launcher or mod compatibility
- Replay, automatic clips, and BedWars detection
- Documentation, website, or download problems
- Feature suggestions

The builder runs locally in the browser. It can copy the finished report as
Markdown or download it as a `.md` file; it does not claim to submit anything.

Until the public Recordable Community repository exists, share port reports
through the community Discord link. Problems with the original Fabric mod
belong with the original project's support channels.

## Include these details

- A short summary and the correct project
- Minecraft, loader, mod, Java, and launcher versions
- Operating system and relevant mod, shader, or resource-pack list
- Exact steps to reproduce
- Expected and actual results
- Whether it happens always, sometimes, or once
- A focused `latest.log` excerpt or relevant test report

For visual bugs, include the screen name, GUI scale, resolution, fullscreen
state, shaders, and OptiFine/Fast Render state. For recording issues, include
the encoder, resolution, FPS, and Capture Test result. For FFmpeg issues,
include the Test FFmpeg report and whether the install is managed, custom, or
from `PATH`.

## Protect private information

Logs and recordings can contain usernames, server addresses, chat, local file
paths, or account details. Remove anything private before sharing. Never
include passwords, access tokens, or private server information.
